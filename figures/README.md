# Figures of the papers

Empty for now. Each figure of the plan (F1 to F10) gets one script here, named `f05_calibration.py`, `f06_envelope.py` and so on.
`make figures` runs every script `figures/f*.py`, after the script of the theory note.

Rules for a figure script: it reads the results database, it writes one PDF (vector) next to itself,
and it prints the numbers quoted in the text.
